# ПЗ №2 - одноразовий блокнот (XOR), обмін по мережі

1. `node keygen.js 4096` - створити блокноти (keys/alice, keys/bob)
2. Термінал 1: `node server.js 5000` - Боб
3. Термінал 2: `node client.js 127.0.0.1 5000` - Аліса
4. Вводьте повідомлення в будь-якому терміналі та натискайте Enter

`node demo.js` - демонстрація властивостей шифру без мережі.
Потрібен лише Node.js, сторонніх бібліотек немає.
